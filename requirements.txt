# ---------------------------------------------------------------------------
# The Relay — runtime dependencies (pinned to major versions only)
#
# Deliberately small. Every entry here earns its place:
#
#   pypdf            PDF text extraction. Pure Python, no native build.
#   pydantic         Typed configuration + request/response schemas.
#   pydantic-settings  Loads config from environment / .env with validation.
#   pyyaml           Human-editable experiment + retrieval config files.
#   httpx            Async HTTP client for the Groq adapter (and the
#                    stand-in's optional HTTP mode).
#   redis            redis-py client, used with asyncio.
#   fastembed        ONNX-based embeddings + cross-encoder reranking.
#                    Chosen over sentence-transformers because it needs no
#                    PyTorch (~2.5 GB on Windows) for the same job.
#   rank-bm25        Classic lexical retrieval. Technical papers contain
#                    exact tokens ("QK^T", "Mimi", "H-Net") that dense
#                    embeddings blur, so we need both retrievers.
#   numpy            Vector maths.
#   fastapi+uvicorn  Thin HTTP surface so the load generator can drive the
#                    pipeline over the network rather than in-process.
#   pytest           Unit + integration tests.
#   pytest-asyncio   Tests for async code paths.
# ---------------------------------------------------------------------------
